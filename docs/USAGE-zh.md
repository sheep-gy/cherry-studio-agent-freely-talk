# Cherry AI 工作室 · 便携版

> 单文件、免安装、用完还原的 Cherry Studio 增强外挂

---

## 一、它解决什么问题

Cherry Studio 里 AI Agent 互相发消息，有两个拦路虎：

| 问题 | 表现 |
|---|---|
| **① 每次都要人工点「允许」** | Agent 之间发消息弹审批卡片，不点就不走 |
| **② 被消息唤醒的 Agent 发不出消息** | 报 `SESSION_TOOL_FORBIDDEN` / `no interactive responder`，连卡片都不弹 |

本程序把两个都解决了：**Agent 之间可以自由互发、多轮对话，全程无需人工确认。**

---

## 二、怎么用

**双击桌面上的「Cherry AI 工作室」就行。** 没有别的步骤。

它自动做完这些：

```
双击
 ├─ 1. 自动找本机的 Cherry Studio
 │      （注册表 → 常见安装路径 → 开始菜单快捷方式 → 运行中进程 → 磁盘扫描）
 ├─ 2. 备份并临时修改 app.asar（放开 Agent 跨会话限制）
 ├─ 3. 带调试端口启动 Cherry Studio
 ├─ 4. 后台注入守护脚本，自动点「允许」卡片
 └─ 5. 你关掉 Cherry → 立即还原 app.asar → 自己退出
```

**关键点：用完还原。** 你不需要它的时候，Cherry 安装目录跟没动过一样。

---

## 三、几个设计细节

### 用完即还原
退出时把 `app.asar` 恢复原样。不在你电脑上留改动。

### 崩溃也能自愈
如果程序被强杀、或电脑突然断电，改动会残留。下次启动时会**先自动还原干净再重新开始**，不会越积越乱。

实测日志：
```
[13:50:20] 自愈：已还原上次残留的 app.asar 修改（app.asar.585c13da6593f2ad.orig）
[13:50:22] 当前 asar 状态：pristine
[13:50:23] 补丁已生效（退出时自动还原）
```

### 升级不怕
备份按 asar 文件指纹命名（`app.asar.<md5前16位>.orig`）。**Cherry 升级后 asar 变了，会自动建新备份，绝不会拿旧版本的备份去覆盖新版本。**

### 默认值被占用时
单实例锁（本地端口 9336）——重复双击不会出现两个实例重复点卡片。

## 四、首次运行会怎样

1. **可能要授权管理员**：改 `C:\Program Files\...` 需要管理员权限，程序会自己弹 UAC 申请。拒绝的话会降级为"只做自动授权、不改文件"（多轮互通不可用）。
2. **首次备份约 297MB**：几秒钟，只做一次；之后同版本直接复用。

---

## 五、文件在哪

```
%LOCALAPPDATA%\CherryAIStudio\
├─ backup\  app.asar.<指纹>.orig      ← 原始文件备份（297MB，最多保留 2 份）
├─ logs\    app-YYYYMMDD.log          ← 运行日志（出问题看这个）
└─ state.json                          ← 仅运行时存在，正常退出会删掉
```

## 六、注意事项

| 事项 | 说明 |
|---|---|
| **只从这个 exe 启动** | 从原来 Cherry 图标启动的话，自动授权仍有效，但**多轮互通不生效**（没打补丁） |
| **杀毒软件可能误报** | PyInstaller 打包的 exe 常见误报，加信任即可 |
| **Cherry 升级后** | 无需任何操作，下次双击自动处理 |
| **想彻底卸载** | 删掉桌面 exe + 删 `%LOCALAPPDATA%\CherryAIStudio` 整个目录 |
| **想临时不用** | 不双击它，正常开 Cherry 即可（= 完全原始状态） |

## 七、自动批准的范围

只放行这三类，其它审批（删知识库、装 CLI、改配置等）仍然要你手动点：

- `session_send` — Agent 之间发消息
- `session_create` — 新建 Agent 会话
- `install_skill` — 安装技能

想改范围：编辑 `CherryPortable.py` 里的 `WHITELIST` 字典后重新打包。

```
✅ 强杀程序 → asar 保持补丁态、state 文件保留

✅ 关闭 Cherry → 还原为 pristine
```

### 二进制指标
- 单文件 **11MB**，自带 Python 运行时与全部依赖，目标机无需装任何东西
- 运行结束**零临时目录残留**（PyInstaller 单文件包常见的 `_MEI` 垃圾问题已通过清理子进程 PATH 解决）
